# Pre-Service Checklist

Complete this checklist in order before every service.

## On arrival

- [ ] Sign in and check the run of show
- [ ] Review any notes from the Team Lead

## Systems power-on

<!-- TODO: Document power-on order for your specific gear -->

- [ ] Power on all equipment in correct order
- [ ] Confirm network/internet connectivity
- [ ] Launch streaming software

## Video check

- [ ] Camera 1 (main) powered and positioned next to the center table, HDMI run to the switcher's Camera 1 input
- [ ] Camera 2 powered and positioned on the right walkway; wireless link confirmed at the switcher
- [ ] Both cameras set to [standard settings](../hardware.md#standard-camera-settings) (adjust only if lighting demands)
- [ ] Focus dialed in on both cameras using focus assist; toggled off before going live (see [Camera Operator guide](../training/roles.md#camera-operator))
- [ ] Clean signal on all camera inputs
- [ ] Switcher routing confirmed
- [ ] Program output clean

## Audio check

<!-- TODO: Fill in audio monitoring setup -->

- [ ] Audio feed confirmed from FOH or audio interface
- [ ] Levels set and not clipping
- [ ] Monitor mix confirmed

## Stream check

- [ ] Streaming MacBook out of the rig box, plugged in (charger and brick are in the box)
- [ ] OBS open on the MacBook with the correct show profile loaded
- [ ] Primary switcher powered on; all camera inputs live and clean
- [ ] Audio cable connected: Sound Board Output 13 → primary switcher headphone port
- [ ] Audio reaching OBS through the switcher (verify on meters before muting)
- [ ] YouTube stream key confirmed and active in OBS
- [ ] Intro Video scene selected in OBS and looping cleanly
- [ ] Program audio muted in OBS while the intro loop plays
- [ ] ATEM powered on with the recording SSD plugged in over USB 2
- [ ] Bitrate and resolution confirmed in OBS
- [ ] Test stream verified on a second device

## Graphics check

- [ ] ProPresenter running on the graphics laptop with the correct show file loaded
- [ ] NDI output from ProPresenter visible as a source in OBS
- [ ] Lower thirds tested end-to-end (fired from ProPresenter, visible in OBS program)

## Final check before doors open

- [ ] All team members at their stations
- [ ] Communication channel open
- [ ] Team Lead given go/no-go
