# TGC - Livestream Playbook

The official playbook for The Garden Church Livestream Team.

**Live site:** https://the-garden-church.github.io/playbook-livestream

## About

This playbook covers recruitment, expectations, weekend processes, hardware documentation, and training for the Livestream Team.

## Contributing

Content is maintained by the Team Lead. To suggest a change, open an issue or submit a pull request.

## Local development

pip install mkdocs-material
mkdocs serve
